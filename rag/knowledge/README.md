# Insurance AI Copilot Knowledge Base

Place approved `.txt` or `.md` insurance/process documents in this folder.

Examples:

- claims_process.md
- underwriting_guidelines.md
- renewal_process.md
- product_faq.md
- internal_sop.md

The Stage-18 `search_insurance_knowledge` tool retrieves relevant text
from these files and gives it to the LLM as grounded context.

Do not place passwords, API keys, or secrets here.
